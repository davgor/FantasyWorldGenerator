# ML-03 — Native kernel and minimal Unreal runtime proof

## Requested behavior

Port the ML-02 transition into a portable native core, expose it through a generic runtime `.uplugin`, and qualify an immutable source-inclusive package in a clean minimal consumer.

## Proposed mechanism

Keep `Core/` free of Unreal types; wrap it in `Unreal/MathLabRuntime/`; use `Tests/UnrealConsumer/` for compile, load, runtime, serialization, and cooked execution. Compare native results with reviewed ML-01 fixtures.

## Dependencies and unresolved decisions

Depends on ML-02. Before scheduling, record plugin/module name, exact Unreal patch, compiler/toolchain, platform/architecture/targets, CI runner, artifact channel, compatibility manifest, and license. PK04 here means a cooked minimal consumer; the separate game retains its own integration gate.

## Acceptance and evidence

PK02, PK03, the minimal-consumer interpretation of PK04, PK08, and PK10. A Python wheel, JSON export, descriptor-only plugin, editor-only Python call, or mutable Actions artifact cannot satisfy this ticket.
