# ML-01 — Portable contract, taxonomy, identity, units, and fixtures

## Requested behavior

Define the versioned portable contract that both the Python oracle and native kernel can implement without silent semantic mappings.

## Proposed mechanism

Add capability-description, taxonomy, identity, coordinate/unit, PRNG/order/numeric, schema-version, and failure contracts under `Contracts/`, plus independently authored conformance fixtures and invalid-input cases.

## Dependencies and unresolved decisions

Depends on ML-00. Decide legacy `weave/umbral/infernal/holy/primordial` preservation versus the proposed Necrotic/Nature/Radiant/Arcane/Storm vocabulary. Decide aliases, retired IDs, semantic asset-requirement ownership, coordinate frames, numeric tolerances, and versioning policy before freezing fixtures.

## Acceptance and evidence

Explicit mapping decisions; independent seed streams; stable IDs; units/projection; deterministic ordering; unknown-version/ID rejection; reviewed fixtures that test behavior rather than reread implementation constants; exhaustive asset-list traceability.

## Handoff

Start only after ML-00 clean-checkout evidence. Split taxonomy and numeric/ordering decisions into reviewable records if they cannot close together.
