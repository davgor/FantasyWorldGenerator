# PPL - People bases and wearable requirements

30 individually tracked production jobs. All start unchecked. Shared output/acceptance contracts are in [README](README.md); exact structured records are in [manifest.json](manifest.json).

Each checkbox means the complete job (source, derivatives and import verification), not merely an image or draft.
